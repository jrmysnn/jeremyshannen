# Jeremy & Shannen Wedding Invitation

A responsive, static wedding invitation website made for GitHub Pages. The logo, portraits, new couple photo, and transparent walker sprite sheets in `assets/` are local files. The walker sprite sheets are derived from the supplied GIFs. Display fonts load from Google Fonts, with system fallbacks if they are unavailable.

## Publish with GitHub Pages

1. Add the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
4. GitHub Pages will provide the published site URL in the same settings panel.

No build step is required. The countdown is set to December 20, 2026 at 2:30 PM Philippines Time. The walkers approach across the final 120 days. The downloadable calendar invite is `calendar.ics`.

## RSVP

No RSVP contact or response service was provided, so the site does not pretend to submit guest responses. Add an RSVP email address or form service before sharing the invitation if you want guests to reply through the site.

## Photos

The portraits were selected from the supplied `weddinginvitationwebsite` folder, rotated using their camera metadata, resized, and compressed for the web.
